# X concep AI Multi-Route 3D · Meeting · OpenUSD Final Full Stack

기존 GPT Image·Hunyuan3D 운영 흐름을 유지하면서 OpenSCAD 구조 생성, Blender 고품질 자산 처리, 회의 음성 분석, Design State, 자동 Router·Fallback, 검증 등급 및 OpenUSD·Omniverse를 통합한 최종 기준 코드임.

## Quick Start

```bash
cp .env.example .env
docker compose up --build
```

- UI: `http://localhost:8080`
- 통합 상태: `http://localhost:8080/api/system-status`
- Smoke Test: `./scripts/smoke-test.sh`

- 동작·OpenUSD임

# X concep AI Omniverse Kit App

본 디렉터리는 NVIDIA Kit SDK 런타임 자체가 아니라, Kit App Template에 복사하여 사용할 앱/확장/스크립트 소스임.

적용 기술임.

- OpenUSD Layer Composition
- VariantSet 기반 설계안/회의 Revision 전환
- UsdPhysics/PhysX 준비 데이터
- Asset Converter
- Asset Validator
- Nucleus 게시
- Live Collaboration용 Layer 구조
- `omni.kit.livestream.app` WebRTC 스트리밍
- `omni.kit.livestream.messaging` 브라우저 양방향 메시지 확장 기반

실행은 `docs/OMNIVERSE_KIT_DEPLOY_KO.md`를 따름.
